# Rare Medicine Locator

Rare Medicine Locator is a full-stack healthcare web application designed to help patients locate rare medicines from nearby pharmacies. The platform allows users to search for medicines, send medicine requests, and connect with verified pharmacies. Pharmacies can manage their inventory and respond to patient requests efficiently.

## Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* Axios
* React Router DOM

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* JWT Authentication
* bcryptjs
* Multer
* CORS
* dotenv

### Cloud & Deployment

* Vercel (Frontend Hosting)
* MongoDB Atlas (Database)

## Database Models

* **User** – Stores patient and admin details.
* **Pharmacy** – Stores pharmacy information and verification status.
* **Medicine** – Stores medicine details and descriptions.
* **Inventory** – Manages medicine stock available in pharmacies.
* **Request** – Tracks medicine requests and responses.
